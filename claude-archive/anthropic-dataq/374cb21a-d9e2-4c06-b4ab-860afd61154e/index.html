Done. Cleaned up the test server.

What was built

You can now join any two datasets from the dataset page, on a key you pick. A Join another dataset panel sits between "Run an action" and "Suggestions": choose the other table, choose the column pairs, see what the join will do, run it.

Backend

Composite keys — JoinParams (backend/src/dataq/services/operations.py:466) now takes on: [{left, right}, ...]. The one-pair left_column/right_column spelling still works and normalises into on, because a Suggestion carries a literal stored request body and the agent's create_join writes that shape.

This directly answers the case from commit 80972cd: a per-(country, action) table has neither column unique alone, so either alone multiplies rows and only the pair annotates them. Verified on real data — 15,000 auth rows joined to a 32-row pairs table stay 15,000 rows; on country alone the op still refuses with 15,000 rows into 60,000.

A collision bug that was unreachable until now — run_join_op projected l.* plus the right side's columns and only excluded the key. Any other shared name produced two columns of that name; DuckDB returns ['k','n','n'] without complaint, and the catalog stores one column per name per version. Joining two frequency aggregates, which both have n, is enough to hit it. The transform-side join already checked for this, so the check is now shared rather than restated.

Preview before the job — new backend/src/dataq/services/join_plan.py, modelled on feature_plan.py. candidates() answers "what could this be joined to" from profiles alone; preview() measures the actual join for the price of two counts, a GROUP BY and a bounded probe. Its two data checks are extracted from jobs/executor.py and shared with build_join_source.

New endpoints: GET /api/datasets/{id}/join-candidates, POST /api/datasets/{id}/join-preview.

Frontend

frontend/src/components/JoinPanel.tsx — dataset picker (candidates grouped first, everything else below, since the semantic layer proposes rather than gates), per-pair column selects with "Add a column to the key", how/prefix/output name, and a live outcome strip that goes amber on a thin match and red on fan-out or collision. allow_fanout only appears once the preview says that's what this is. Join suggestions gained an Edit button that loads them into the panel instead of firing.
